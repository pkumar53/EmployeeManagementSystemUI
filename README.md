# Employee Management System - Frontend

Frontend application for the Employee Management System built using **React and Vite**.

The application communicates with the Employee Management System backend APIs built using FastAPI.

## Features

The application provides:

- Employee dashboard
- View employee list
- Add employee
- Edit employee
- Delete employee
- Employee form validation
- Communication with FastAPI backend

## Technology Stack

- React
- Vite
- JavaScript
- Axios
- CSS
- Node.js
- npm

## Prerequisites

Before running the application, install:

- Node.js 18+
- npm
- Git

## To Execute
cd EmployeeManagementSystemUI
npm install
npm run dev
